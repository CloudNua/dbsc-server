# Contributing

Thank you for your interest in this project.

## Issues

Issues are welcome. Use issues to report bugs, to report differences between this
package and the DBSC specification, and to request features.

When you report a bug, include the package version, the runtime and its version, and
the steps to reproduce the problem.

## Pull requests

This project does not accept unsolicited pull requests. The maintainer writes the code.
This policy keeps the review surface of a security-critical library small.

If you want to propose a change, open an issue first. The maintainer can then invite a
pull request for it.

## Security problems

Do not open a public issue for a security problem. Follow the steps in
[SECURITY.md](./SECURITY.md).
